# Fuentes del Caso 3

Fuente: Instituto Nacional de Estadística, Encuesta de Hogares 2025 - https://anda.ine.gob.bo/index.php/catalog/256. Fecha de acceso documentada: 15/11/2026.

Descargue desde el catálogo los módulos EH2025_Persona.sav y EH2025_Discriminacion.sav y consérvelos juntos en una carpeta local. Desde la raíz del caso puede verificarlos con `python data/conectar.py /ruta/a/modulos`.
