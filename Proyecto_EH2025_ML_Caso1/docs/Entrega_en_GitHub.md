# Entrega en GitHub

El [índice de los tres casos](../../README.md) reúne los informes, cuadernos y reportes EDA. Para este caso consulte la [documentación técnica](../README.md), el [informe final](Informe_Caso1_EH2025_Final.pdf) y la [verificación de la ingesta con DuckDB](Revision_Parte1_Caso1.md). El [explorador de resultados](Explorar_resultados.html) se abre en un navegador después de descargar la carpeta.

El dataset municipal agregado se distribuye en CSV y Parquet. El dataset individual académico se regenera en un directorio privado con los módulos autorizados del INE. Su tratamiento se documenta en [Dataset individual académico](Dataset_individual_academico.md).
